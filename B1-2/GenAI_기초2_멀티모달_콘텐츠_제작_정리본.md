# GenAI 기초 2: 멀티모달 콘텐츠 제작

> 가상 또는 실제 브랜드를 선정하고, 생성형 AI를 주된 소스로 활용해 **10초 이내 광고 영상**과 **스토리보드 PDF**를 제작하는 과제입니다.

---

## 과제 한눈에 보기

이 과제의 핵심은 여러 AI 도구를 많이 사용하는 것이 아닙니다.

다음 제작 흐름을 직접 설계하고, 각 단계에서 왜 그런 선택을 했는지 설명하는 것이 핵심입니다.

```text
기획 의도
→ 프롬프트 작성
→ 이미지·영상·오디오 생성
→ 결과물 검토 및 수정
→ 통합 편집
→ 10초 이내 광고 영상 완성
```

### 최종 제출물

| 산출물 | 형식 | 핵심 조건 |
|---|---|---|
| 스토리보드·기획 문서 | PDF 1개 | 브랜드, 캠페인 목표, 씬 구성, 도구와 프롬프트 기록 |
| 광고 영상 | MP4 1개 | 10초 이내, AI 생성 시각·청각 요소 포함 |

### 반드시 사용해야 하는 생성 도구

- 이미지 생성 AI 1종 이상
- 비디오 생성 또는 변환 AI 1종 이상
- 오디오 생성 AI 1종 이상

### 최종 영상의 필수 요소

- 길이: 10초 이내
- AI로 생성된 시각 요소 포함
- AI로 생성된 청각 요소 1개 이상 포함
  - 음성
  - 효과음
  - 배경음악
- 단순 컷 나열이 아닌 스토리라인 또는 명확한 가치 메시지
- 마지막 3~5초에 브랜드 인지 장치 1개 이상 포함
  - 로고
  - 브랜드명
  - 슬로건
  - CTA

# 1. 미션 소개

텍스트로 이미지 한 장을 만드는 일은 이제 누구나 할 수 있습니다.

하지만 여러 이미지에 움직임과 소리를 더하고, 하나의 일관된 브랜드 경험으로 완성하는 것은 다른 문제입니다.

광고, 티저 영상, 숏폼 캠페인처럼 시각과 청각을 동시에 활용하는 콘텐츠를 만들려면 다음 요소를 함께 설계해야 합니다.

- 어떤 브랜드를 보여줄 것인가
- 누구를 대상으로 할 것인가
- 어떤 메시지를 전달할 것인가
- 어떤 화면과 소리를 사용할 것인가
- 어떤 AI 도구를 어떤 목적으로 사용할 것인가
- 결과가 기대와 다를 때 프롬프트를 어떻게 수정할 것인가
- 각 소스를 어떻게 하나의 영상으로 통합할 것인가

이번 미션의 목표는 기획 의도가 프롬프트를 거쳐 최종 영상으로 구현되기까지의 전체 제작 파이프라인을 스스로 설계하는 것입니다.

가상 또는 실제 브랜드 1개를 선택하고, 스토리보드 문서를 만든 뒤, AI 도구를 주된 소스로 활용하여 10초 이내 광고 영상을 완성합니다.

중요한 것은 다음 흐름을 설명할 수 있는지입니다.

```text
기획 의도 → 프롬프트 → 결과물 → 통합 편집
```

또한 실제 멀티모달 제작에서 자주 발생하는 다음 문제를 고려해 현실적인 제작 전략을 세워야 합니다.

- 캐릭터 또는 화풍 불일치
- 해상도와 화면 비율 혼재
- 오디오 톤 미스매치
- 크레딧 부족
- 생성 대기열
- 도구별 플랜 제한

# 2. 최종 결과물

AI 기반 브랜드 광고 패키지에는 다음 2가지 산출물이 포함되어야 합니다.

## 2.1 스토리보드·기획 문서

### 제출 형식

- PDF 1개

### 문서 전체에 포함할 항목

- 브랜드 아이덴티티
- 캠페인 목표
- 핵심 메시지
- 씬 구성
- 사용 도구 목록

### 모든 씬에 공통으로 포함할 필드

| 필드 | 작성 내용 |
|---|---|
| 씬 번호 | 씬의 순서 |
| 씬 길이 | 초 단위 길이 |
| 목표 메시지 | 해당 씬이 전달해야 할 메시지 한 문장 |
| 화면 구성 | 구도, 피사체, 배경, 텍스트 유무 |
| 내레이션 또는 화면 카피 | 들려주거나 보여줄 문구 |
| 사용 도구와 목적 | 이미지·비디오·오디오 도구와 사용 이유 |
| 입력 프롬프트 | 도구에 실제로 입력한 원문 |
| 출력 결과 요약 | 생성 결과를 한 줄로 요약 |
| 결과 파일명 또는 링크 | 생성 결과를 확인할 수 있는 파일명 또는 링크 |

파일명 규칙은 자유지만 전체 프로젝트에서 일관되게 유지해야 합니다.

### 추가 권장 사항

최소 1개 씬에 대해 다음 내용을 기록하는 것이 권장됩니다.

- 프롬프트 수정 전
- 프롬프트 수정 후
- 수정한 이유
- 수정 결과의 변화

## 2.2 광고 영상

### 제출 형식

- MP4 1개

### 필수 조건

- 영상 길이: 10초 이내
- 영상과 오디오의 주된 소스: 생성형 AI 결과물
- AI로 생성된 시각 요소 포함
- AI로 생성된 청각 요소 1개 이상 포함

### 권장 최대 인코딩 스펙

최대 스펙은 필수 사항이 아닙니다.

| 항목 | 권장 스펙 |
|---|---|
| 해상도 | 1080p |
| 프레임레이트 | 24~30fps |
| 비디오 코덱 | H.264 |
| 오디오 코덱 | AAC |

최대 스펙 달성이 어려운 경우 해상도는 **720p 이상**을 허용합니다.

# 3. 과제 목표

과제를 마친 후 다음 내용을 스스로 설명할 수 있어야 합니다.

- 텍스트·이미지·비디오·오디오 생성 도구의 역할과 차이
- 각 생성 도구의 강점과 약점
- 기획 의도에 맞는 결과를 얻기 위해 프롬프트를 설계하고 수정한 과정
- 동일한 요구를 여러 도구로 시도했을 때 발생한 결과 차이
- 특정 도구를 선택한 이유
- 생성된 미디어 소스를 해상도·비율·톤앤매너 관점에서 정리한 방법
- 여러 미디어 소스를 하나의 광고 영상으로 통합한 흐름

# 4. 기능 요구 사항

다음 요구사항을 모두 충족해야 합니다.

## 4.1 브랜드와 캠페인 정의

브랜드는 가상 브랜드 또는 실제 브랜드 중 1개를 선택합니다.

### 브랜드 아이덴티티 필수 요소

- 타겟
- 톤앤매너
- 차별점(USP)

### 캠페인 필수 요소

- 광고 목적
  - 인지
  - 전환
  - 리텐션 등
- 핵심 메시지 1개
  - 한 문장으로 명확하게 작성

## 4.2 스토리보드 문서화

영상 제작 전에 씬 단위로 스토리보드를 작성합니다.

- 모든 씬의 필수 필드를 누락 없이 작성
- 최소 1개 씬에서 프롬프트 수정 전·후 비교
- 무엇을 바꿨는지 기록
- 왜 바꿨는지 기록
- 변경에 따라 결과가 어떻게 달라졌는지 기록

## 4.3 멀티모달 생성 도구 사용

다음 도구를 각각 1종 이상 사용합니다.

- 이미지 생성 AI
- 비디오 생성 또는 변환 AI
- 오디오 생성 AI

도구 선택은 자유입니다.

다만 스토리보드에 각 도구를 해당 목적으로 선택한 이유를 간단히 기록해야 합니다.

## 4.4 영상 길이와 구성

- 최종 영상은 10초 이내로 제작
- AI 생성 시각 요소 포함
- AI 생성 청각 요소 1개 이상 포함

청각 요소는 다음 중 하나 이상이면 됩니다.

- 음성
- 효과음
- 배경음악

## 4.5 서사와 메시지

단순히 여러 컷을 이어 붙이는 방식은 충분하지 않습니다.

다음 중 하나 이상을 만족해야 합니다.

### 구조 A: 기승전결

```text
문제 제시 → 전환 → 해결 또는 제안
```

### 구조 B: 명확한 가치 메시지

```text
누구에게 → 어떤 가치를 제공하는지
```

### 마지막 3~5초 필수 요소

브랜드 또는 제품을 인지할 수 있는 다음 장치 중 1개 이상을 포함합니다.

- 로고
- 브랜드명
- 슬로건
- CTA

# 5. 보너스 과제

보너스 과제는 선택 사항입니다.

## 보너스 1. 립싱크 적용

- 인물이 말하는 장면 1개 이상 추가
- 입모양과 대사를 자연스럽게 일치

## 보너스 2. 동일 스토리보드를 다른 도구로 재제작

- 이미지 또는 비디오 생성 도구를 다른 도구로 변경
- 동일한 씬 1~2개 재제작
- 결과 차이를 비교할 수 있도록 구성

## 보너스 3. 플랫폼별 화면 비율 버전 제작

동일한 스토리보드로 화면 비율 버전을 2개 이상 제작합니다.

예시:

- 16:9 — 유튜브
- 9:16 — 숏폼·릴스 표준, 1080×1920

# 6. 제약 사항

## 6.1 소스와 저작권

- 직접 촬영한 영상은 사용하지 않습니다.
- 유료 스톡 영상 소스는 사용하지 않습니다.
- 모든 시각 및 청각 소스는 생성형 AI를 통해 만들어진 결과물이어야 합니다.
- 저작권·윤리 문제가 큰 딥페이크 생성을 금지합니다.
- 혐오·선정성·폭력 등 유해 콘텐츠 생성을 금지합니다.

## 6.2 편집 도구 사용 범위

Premiere Pro, CapCut 등의 영상 편집 소프트웨어는 통합 편집 목적으로 제한적으로 사용합니다.

### 허용되는 작업

- 컷 편집
- 자막
- 간단한 색보정
- 오디오 레벨 조정

영상의 핵심 비주얼과 오디오는 AI 생성 결과물을 주된 소스로 유지해야 합니다.

## 6.3 비용과 크레딧 관리

영상 생성은 크레딧 소모가 큰 경우가 많습니다.

따라서 이미지 생성 단계에서 스토리보드를 최대한 확정한 뒤 영상 변환을 시도하는 방식이 권장됩니다.

크레딧이 부족한 경우 다음 전략 중 최소 1개를 선택해 범위를 조정합니다.

- 씬 수를 줄이고 메시지 밀도를 높이기
  - 예: 6씬 → 4씬
- 정지 이미지와 짧은 모션 중심으로 구성하기
  - 패닝
  - 줌
  - 루프
- 동일한 스타일 레퍼런스를 고정해 재생성 횟수 줄이기

## 6.4 도구 접근성 대응

특정 도구가 대기열이나 플랜 제한으로 막힐 수 있다는 점을 고려해야 합니다.

이미지·비디오·오디오 각각에 대해 대체 도구를 1개 이상 준비합니다.

도구명만 기록해도 됩니다.

### 대체 도구 예시

- 비디오 생성·변환: Pika, Kling 등
- 오디오: 여러 생성 도구 중 선택
- 음성 합성: 여러 TTS 중 선택

## 6.5 캐릭터와 스타일 일관성

캐릭터와 스타일을 일관되게 유지하기 위해 다음 기능을 활용하는 것이 권장됩니다.

- Character Reference
- Style Reference
- cref
- sref
- ControlNet 계열 제어 기능

이 기능을 사용했다면 스토리보드 또는 발표에서 다음 내용을 설명할 수 있어야 합니다.

- 어떤 파라미터를 고정했는가
- 어떤 레퍼런스를 고정했는가

# 7. 결과 예시

아래 예시는 정답이 아니라 참고용입니다. 실제 문구와 디자인은 달라도 됩니다.

## 7.1 브랜드 아이덴티티 예시

- 브랜드명: NeoSeoul
- 타겟: 10~20대(트렌디·스트릿)
- 톤앤매너: 사이버펑크, 네온, 우천의 서울, 시네마틱
- USP: “서울 감성 + 미래적 실루엣”을 결합한 한정 드롭
- 핵심 메시지: “오늘 밤, 너의 서울을 입어라.”

## 7.2 스토리보드 씬 예시

### 씬 1: Intro

| 항목 | 내용 |
|---|---|
| 씬 길이 | 6초 |
| 목표 메시지 | 브랜드의 세계관인 서울·네온·비를 한 컷에 각인 |
| 화면 구성 | 네온사인이 반사되는 젖은 도로, 인물 실루엣, 로고 없음 |
| 내레이션·카피 | “서울의 밤은, 다시 태어난다.” |
| 이미지 생성 | Midjourney — 키 비주얼 생성 |
| 비디오 변환 | Runway — 이미지를 짧은 모션 컷으로 변환 |
| 오디오 | Suno — 로파이 비트와 빗소리 |
| 출력 결과 요약 | 네온·우천·도시 질감이 강한 키 비주얼 확보 |
| 결과 파일명 | `scene01_keyvisual.png` / `scene01_motion.mp4` / `scene01_bgm.wav` |

**입력 프롬프트 예시**

```text
cyberpunk neon Seoul night street, rain reflections,
cinematic lighting, 8k, shallow depth of field
```

## 7.3 프롬프트 수정 전·후 기록 예시

### 씬 2 프롬프트 개선 로그

| 구분 | 내용 |
|---|---|
| 수정 전 의도 | 인물 클로즈업 |
| 문제 | 얼굴 디테일이 과장되어 브랜드 톤과 불일치 |
| 수정 후 변경 | 인물은 실루엣 중심, 의상 텍스처 강조 |
