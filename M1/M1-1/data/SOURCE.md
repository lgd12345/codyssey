# 2023~2025년 KAMIS 딸기 소매가격 출처와 수집 기록

## 공식 출처

- 제공기관: 한국농수산식품유통공사(aT), KAMIS 농산물유통정보
- [공식 농산물 소매가격 기간별 조회](https://www.kamis.or.kr/customer/price/agricultureRetail/period.do)
- [공식 화면의 차트 스크립트](https://www.kamis.or.kr/js/customer/price/agricultureRetail/period_daily.js)
- 요청: 공식 조회 경로의 `action=dailyChartByAjax&rank=1`에 조건을 폼 값으로 POST
- [별도 Open API 명세](https://www.kamis.or.kr/customer/reference/openapi_list.do?action=detail&boardno=17)
- [공공데이터포털의 별도 API](https://www.data.go.kr/data/15156057/openapi.do)
- 수집일: 2026-11-18. 각 원본의 정확한 UTC 시각은 `source_manifest.json`에 기록합니다.

사용자가 지정한 **2023-01-01~2025-12-31**을 **월별 36개 구간**으로 나누어 새로 수집했습니다.
이전 114개 분석의 별도 백업은 만들지 않았습니다. 현재 원본은 이번 3년 수집의 재현을 위해 보관합니다.

## 고정 조건

| 항목 | 실제 요청값 |
|---|---|
| 가격 종류 | 소매가격 |
| 지역 | 서울, `countycode=1101` |
| 부류·품목 | 채소류 `200`, 딸기 `226` |
| 품종 | 설향, `kindcode=00` |
| 등급 | 상품, 웹 `productrankcode=1`, 차트 `rank=1` |
| 단위 | 500g, `convert_kg_yn=N`, 분석 단위 원/500g |
| 집계 | KAMIS 제공 평균 계열(전통시장·유통업체) |
| 요청 기간 | 2023-01-01~2025-12-31 |
| 유효 관측 기간·수 | 2023-01-02~2025-12-31, **347개 고유 날짜** |

웹 조회 rank `1`은 Open API의 등급코드 `04`와 구별합니다.
월별 HTML 폼의 요청 조건과 JSON caption의 품목·품종·등급·단위를 확인합니다.
날짜는 한 달 안의 월/일 표기를 요청 연도와 결합하여 정합니다. 범위 밖·중복 날짜와 배열 길이 불일치는 오류로 중단합니다.

## 원본과 분석 파일

- `source/*.json`: 36개월의 원본 응답 바이트. 평균·전통시장·유통업체 계열 포함.
- `source/*.html`: 같은 조건의 공식 조회 폼 확인용 응답 36개.
- `source_manifest.json`: 월별 URL·매개변수·UTC 시각·HTTP 상태·JSON/HTML SHA-256.
- `monthly_collection.csv`: 반환 관측 수가 0인 달을 포함한 36개월 수집 기록.
- `strawberry_raw.csv`: 평균 계열 추출 347행.
- `strawberry_clean.csv`: 유효 가격·단위·날짜·중복 확인 후 347행.
- `calendar_coverage.csv`: 1,096일 중 관측 347일, 날짜 응답 없음 749일, 가격 결측 0일.
- `monthly_summary.csv`: 빈 달의 평균·중앙값·최저·최고는 빈 값이며 0원이 아닙니다.
- `annual_summary.csv`: 각 연도의 실제 관측값 통계. 연중 전체 가격을 보장하는 지수가 아닙니다.

원본 평균의 원천 시장 표본과 세부 가중 방식은 별도 확인 안 됨입니다.
원본 가격은 결측·0원 이하·중복 날짜가 0건이어서 정제 과정에서 삭제한 행도 0건입니다.
20% 초과 변화율 6건은 후보로 남겼으며 3건은 장기 관측 공백 후의 비교입니다.
749일을 0원·보간·앞값으로 채우지 않았습니다. 원본 가격을 만들지 않기 위한 선택입니다.

## 접근과 이용 조건

이번 공개 조회는 로그인·API 키 없이 성공했습니다. 외부 서비스 변경 시 수집이 실패할 수 있습니다.
공개 화면용 요청 경로이므로 장기적인 API 계약이 보장되는지는 확인 안 됨입니다.
저장된 원본으로 분석은 네트워크 없이 재현할 수 있습니다.

공공데이터포털의 별도 API에는 무료·이용허락범위 제한 없음으로 안내되어 있습니다.
**이번 KAMIS 웹 차트 응답의 재배포 허용 범위는 확인 안 됨**입니다.
공식 화면이 연결한 [aT 저작권보호정책](https://www.at.or.kr/html/member/at_acount_3.html)은
이전 접속에서 HTTP 400을 반환하여 본문을 확인하지 못했습니다.
외부 재배포 전에는 해당 경로의 이용 조건을 확인해야 하며, 데이터 미배포 시에도 수집 코드·조건·획득 방법을 제공합니다.
